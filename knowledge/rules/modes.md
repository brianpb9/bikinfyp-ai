# Modes — camera + talent contract (14)

One mode per video. Permitted deviations: hook override, CTA override (default SELLING). Any segment whose camera contradicts its governing mode fails the gate.

| Mode | Camera | Talent | Best for | Never |
|---|---|---|---|---|
| GENERAL | light handheld, medium, natural follow | doing an everyday activity while talking | lifestyle, F&B, wearables | static macro |
| SELFIE | arm-length, eye level, static or micro-drift | speaks straight to lens | testimonial, skincare, confession | wide follow shots |
| MIRROR_SELFIE | static via mirror, phone visible | pose, OOTD, product raised to mirror | fashion, accessories, try-on | phone hidden |
| ASMR | extreme close-up / macro, static, sound-forward | hands/mouth/texture, minimal talking | F&B, textures, soap, unboxing | talking-head framing in body |
| PODCAST | static medium, mic in frame | relaxed opinion talk | education, storytime | movement |
| STREAM | static webcam, gaming setup | reacts, talks to chat | gadgets, community products | outdoor |
| STEADICAM | smooth follow, wide→medium | walking, entering rooms | reveals, day-in-life, fashion walk | static macro |
| HANDHELD | rough handheld, low angle, flare | energetic, spontaneous | motion hooks, outdoor | polished static |
| CCTV | high-angle static, fisheye, grain | candid "caught on camera" | anomaly hooks, comedy | selfie |
| SELLING | medium selfie, product raised beside face, label to lens | presenter, holds still | CTA / product hero segment | product hidden |
| CAR_TALKING | static dashboard, window light | talks while parked/driving | confession, opinion | product demo |
| ANGRY_MODE | selfie/medium static | annoyed expression, big gestures | pain hooks, rants | CTA |
| HAPPY_MODE | selfie/general | smiling, energy up | payoff, unboxing | pain hook |
| CRYING | close selfie static | emotional | storytime, before-state | product hero |

Override rules: hook override only for modes marked usable as hook (SELFIE, HANDHELD, CCTV, ANGRY_MODE, CRYING, ASMR). CTA override normally SELLING; ASMR/no-face formats may keep ASMR for CTA if the CTA is a hands-only hero shot with spoken VO off camera.
