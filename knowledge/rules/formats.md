# Formats — beat grammar + product-entry rule + hook levels

Segments = 4–6s each. 15s→3, 20s→4, 30s→5–6, 45s→7–8. HOOK 3–5s. CTA ≥4s one continuous take.

| Format | Beat sequence (labels) | Product entry | Use when | Proven example |
|---|---|---|---|---|
| Masalah-dulu | PAIN → DEMO/REVEAL → PROOF → CTA | visible but **idle** from frame 1, first handled at 3–5s | problem is common and can be acted out | sepatu flat, kipas |
| Testimonial | CONFESSION → PROCESS (putting on/using) → ZOOM (extreme close-up, brand readable) → APPROVAL/CTA | held in hook, **not yet worn/used** | trust needed, specs invisible | headphone Sony |
| Review-sensori | FACE-FIRST hook → DEMO → PROOF → REACTION → CTA | partial in demo, hero only in CTA | effect not visible (scent, taste, texture) | parfum, sabun |
| Unboxing try-on | BOX/OPEN → REACTION → REVEAL → TRY-ON (transition: fabric over lens) → CTA | product emerges | fashion, wearables | set padel |
| Tanpa wajah | OBJECT hook → DEMO → PROOF → CTA (hands only, VO off camera) | in frame from start | visible transformation; removes face-consistency risk | milk frother |
| Haul / multi-item | HOOK → one segment per item (item name as label) → montage CTA | each item hero in its own segment | 3–5 products, 16:9 or 9:16 | fashion haul |

Beat 3 (ZOOM/PROOF) is where the product is sold; the other beats sell the person. If one beat must be re-rolled to perfection, it's that one.

## Hook levels
- L1 everyday problem, no effects (sepatu, kopi datar) — strongest for common-problem products
- L2 unboxing / reveal (POV from inside the box)
- L3 mechanism demo (studio tools vanishing)
- L4 exaggerated real world (fan in a lava field)
- L5 physics-breaking (fan blows ice) — effect must be in the **foreground**; safe from overclaim because it's obviously impossible; spoken line stays honest

Never open on a pack shot. First frame = face, motion, or object anomaly.
